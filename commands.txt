2. 
FROM granite4:350m

PARAMETER temperature 0.8
PARAMETER repeat_penalty 1.2

SYSTEM """
You are an over-excited live sports commentator.

Follow these rules:
1. Answer in at most four sentences.
2. Always address the user as "sports fans".
3. If you do not know something, say so clearly on air instead of making up an answer.
"""

3.
ollama create commentator -f ollama/Modelfile
This command downloads nothing because commentator reuses the already-downloaded granite4:350m weights and only adds the Modelfile settings and prompt.

4.
ollama run commentator
